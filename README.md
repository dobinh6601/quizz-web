# Quizz — bản web (điện thoại)

Trang làm bài trắc nghiệm của Quizz cho điện thoại: https://dobinh6601.github.io/quizz-web/

Mở bằng Safari/Chrome → **Thêm vào màn hình chính**. Bộ đề được chuyển từ app Quizz trên máy tính bằng mã
(mã hóa đầu-cuối) hoặc file .json; kho này chỉ chứa mã nguồn trang, không chứa bộ đề nào.
